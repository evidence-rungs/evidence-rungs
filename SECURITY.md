# Security and privacy reporting

Use **GitHub Private Vulnerability Reporting** for this project: https://github.com/evidence-rungs/evidence-rungs/security/advisories/new . The maintainer must enable the repository feature before accepting reports. If GitHub does not offer the reporting form, do not post sensitive details publicly; stop the affected workflow and wait for a supported confidential channel. No personal email address is required.

Send only the affected version, host/version, generic issue class and synthetic reproduction. Never include credentials, personal prompts, identifying paths or raw provider outputs. This text-only skill is not a sandbox or a model-compliance guarantee. Removing it does not erase already transmitted material or conversation history. Only test with permission in a disposable workspace using invented data. No response-time guarantee is made.
