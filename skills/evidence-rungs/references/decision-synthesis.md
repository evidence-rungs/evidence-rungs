# Optional: a decision-sensitive alternative

Status: **not yet measured; host/model behavior untested.** Use for a comparison or recommendation only when a plausible competing explanation could change the choice. Ordinary summaries do not need this exercise.

Check the strongest plausible alternative only if it could change the decision. Describe what that alternative explains and which available observation would distinguish it from the current interpretation. For example, an observed improvement might reflect a changed measurement rather than a better product; do not invent that explanation if the evidence gives no reason for it.

Use existing evidence before considering another lookup. No extra search, worker or source quota is required. If the alternatives remain unresolved within the core budget, state the conditional decision and its missing discriminator; do not guess a cause.

Do not pad with both-sides symmetry. A weak objection need not receive equal space, and unrelated contrary links do not establish a competing explanation. If no credible alternative would alter the choice, leave this note unused. It neither promises better decisions nor changes the original safety, privacy or stopping rules.
