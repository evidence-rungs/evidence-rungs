# Optional: source identity during report editing

Status: **not yet measured; host/model behavior untested.** Use only after an explicit request for a long report. A short answer does not activate this extension; it creates no unrequested file or persistent tracking.

Keep source identifiers stable when the outline changes. In the working draft, associate each source with a unique local label and its exact URL, version/date and supporting passage. Keep that label attached to the evidence, not to a section number or current order of appearance. This is a temporary editing aid, not a new storage schema or software dependency.

When moving or combining sections, move each claim with its support. Rebuild display citation numbers from the stable associations after reordering. Verify that each citation still resolves to its original supporting passage. A renumbered citation must not silently acquire a different source; an unsupported claim stays marked or is removed.

Work with the available source packet and original budget. No additional search is required for citation numbering, and no minimum report length, citation count or continuation cycle is set. Write or retain a file only when the user requested that artifact and the host permits it.
