# Technology sources usable in Austria (optional)
Reviewed 2026-10-19; review due 2027-01. Links and original roles only. These international sources do not establish Austrian law. Match exact version, canonical project owner, operating system, and release status.

- https://docs.python.org/3/ — primary: Python language/library documentation; select the installed version, not simply latest.
- https://developer.mozilla.org/ — specialist: web-platform reference and standard links, not the normative specification itself.
- https://learn.microsoft.com/en-us/windows/wsl/ — primary: supported platform configuration, not evidence of a particular machine's state.
- https://github.com/ — primary or practitioner: canonical code/releases/issues; a comment or open issue is not a confirmed released fix.
- https://api.github.com/ — primary metadata API: public canonical repositories; anonymous limits apply and code search requires authorization.
- https://stackoverflow.com/ — practitioner: reproducible programming issues, not upstream guarantees or security by popularity.
- https://superuser.com/ — practitioner: desktop configuration context, not universal production defaults.
- https://serverfault.com/ — practitioner: server operations context, not a version-independent recommendation.
- https://api.stackexchange.com/ — practitioner API: choose the proper site and respect quota/backoff; votes do not establish truth.
